# Lydia CMS: SecureGate — Client-Side HTTPS Enforcer

**Лидия: Безопасный Вход — Клиентская защита авторизации** — это легковесный, отказоустойчивый скрипт на чистом старом JavaScript, разработанный специально для экосистемы CMS Lydia. Модуль предназначен для защиты чувствительных действий пользователя (ввод паролей, авторизация, платежи) от перехвата и передачи данных по незащищенному протоколу HTTP.

## ✨ Основные возможности

* **0% нагрузки на бэкэнд:** Все проверки структуры соединения, анализ 443 порта и редиректы выполняются на стороне клиента силами браузера.
* **Проверка по требованию (On-Demand):** Защита срабатывает только тогда, когда пользователь взаимодействует с защищенным элементом (клик на кнопку или нажатие `Enter` в форме). На обычных контентных страницах фоновые запросы не гоняются.
* **Защита от утечек (Lazy Loading):** Критические скрипты авторизации (`js/auth.js`) физически блокируются от скачивания до тех пор, пока среда не будет признана абсолютно безопасной.
* **Экстренная зачистка данных:** Если форма отправляется по небезопасному HTTP, движок перехватывает событие, полностью стирает локальные базы данных (LocalStorage, SessionStorage), уничтожает сессионные куки, обнуляет поля ввода и жестко перезагружает страницу для защиты устройства.
* **Максимальная обратная совместимость:** Полная совместимость со старыми стандартами ECMAScript (включая Internet Explorer 8+) и корректная обработка блокировок расширения **NoScript**.
* **Режим отладки для разработчиков:** Встроенный переключатель `DEBUG_MODE`. При его включении скрипт выдает стандартное окно `confirm()`, позволяя разработчикам временно обойти блокировку при локальном тестировании (`file://`).

## 🚀 Установка и интеграция

### 1. Настройка шаблона
Добавьте блок вывода критической ошибки и контейнер формы в шаблон вашей страницы авторизации CMS Lydia:

```html
<!-- Блок для вывода жесткой блокировки при отсутствии HTTPS (по умолчанию скрыт) -->
<div id="secure-critical" style="display:none; background:#f8d7da; color:#721c24; padding:15px; border:1px solid #f5c6cb;">
    <strong>Внимание!</strong><br>
    Передача конфиденциальной информации в открытом виде по протоколу http запрещена! Вход заблокирован для защиты ваших данных.
</div>

<!-- Защищаемый контейнер формы (изначально скрыт) -->
<div id="auth-container" style="display: none;">
    <form id="secure-auth-form" action="/login-handler" method="POST">
        <input type="text" name="user" required>
        <input type="password" id="auth-pass" name="pass" required>
        <button type="submit">Подтвердить вход</button>
    </form>
</div>
```

### 2. Подключение скрипта
Подключите библиотеку ядра в самом низу вашей страницы разметки, **строго после футера**, прямо перед закрывающим тегом `</body>`:

```html
    <!-- Разметка футера заканчивается здесь -->
    <footer>...</footer>

    <!-- Движок SecureGate: загружается только после полной отрисовки DOM-дерева -->
    <script type="text/javascript" src="js/secure-gate.js"></script>
</body>
```

## 🛠️ Локальное тестирование

В репозиторий встроен готовый мультиязычный пакет тестов. Чтобы вручную протестировать оценку окружения, перехват ошибок и переключение языков без развертывания локального веб-сервера, просто откройте следующий файл напрямую в любом браузере:
```text
tests/index.html
```

## 📂 Описание структуры файлов и каталогов проекта

*   **`css/`** — Директория со стилями оформления.
    *   `style.css` — Базовые визуальные стили для гарантированного скрытия и отображения модальных форм и окон блокировки.
*   **`js/`** — Ядро модуля и динамические компоненты.
    *   `secure-gate.js` — Основной управляющий скрипт (движок защиты). Перехватывает события, проверяет HTTPS и очищает кэш.
    *   `auth.js` — Тестовый изолированный модуль авторизации. Загружается асинхронно только в безопасной среде.
    *   `billing.js` — Тестовый модуль платежного шлюза для демонстрации ленивой загрузки (Lazy Loading).
*   **`tests/`** — Пакет автоматизированного тестирования плагина.
    *   `index.html` — Базовый англоязычный тестовый движок. Проверяет ООП-логику и HEAD-запросы без зависания UI.
    *   `index_ru.html` — Локализованный русскоязычный тестовый движок с перекрестной ссылкой для проверки кириллицы.
*   **`index.html`** — Главная презентационная страница проекта и документация на английском языке.
*   **`index_ru.html`** — Презентационная страница и точка входа для тестов на русском языке.
*   **`.gitignore`** — Системный файл, блокирующий попадание мусора операционной системы и редакторов кода в репозиторий.
*   **`LICENSE`** — Официальный текст международной лицензии MIT.
